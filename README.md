# Blush Studio — demo salon website
Static HTML/CSS/JS demo by Malaak. All names, prices, phone numbers and reviews are sample content.
- Edit pages: change content in `build.py` and run `python3 build.py` (or edit the .html files directly).
- WhatsApp number: change `WA` at the top of `script.js`.
- Bookings are NOT stored: the form builds a WhatsApp message the client sends to the salon. For live availability connect Fresha/Setmore/Calendly or a form backend.
- Hosted free on GitHub Pages (main branch, root).
